own-tube — свой клиент YouTube (рабочее название), Windows x64, версия 0.2.3

Запуск: распакуйте архив в любую папку (например D:\Programs\own-tube) и запустите own-tube.exe.
Окно работает на Microsoft Edge WebView2 — он уже есть в Windows 10/11.

Что внутри
- own-tube.exe и папка _internal — сама программа.
- tools\ffmpeg.exe — встроенный плеер и загрузки, tools\mpv.exe — плеер «в отдельном окне»,
  tools\deno.exe — движок JavaScript, который нужен yt-dlp для YouTube.
  Откуда они взяты и их SHA-256 — в tools\SOURCES.txt.
- SHA256SUMS.txt — контрольные суммы всех файлов.

Где данные
- %APPDATA%\own-tube: settings.json (настройки), own-tube.db (история, плейлисты, подписки), own-tube.log.
- Загрузки по умолчанию: папка «Видео\own-tube» (меняется в настройках).

Что нового в 0.2.3
- Быстрее: список (поиск, разделы, канал) приходит одним запросом, повторные открытия показывают сохранённое
  сразу и обновляют в фоне; карточки-заглушки вместо пустого экрана; при наведении на карточку поток видео
  готовится заранее, клик открывает ролик почти мгновенно. Запуск программы заранее «прогревает» соединения.
- «Показать ещё» и бесконечная прокрутка: поиск, Главная, Подписки, разделы, каналы, VK.
- Shorts: вертикальный плеер. Колесо мыши, стрелки ↑ ↓, свайп — следующий и предыдущий; пробел — пауза, M — звук.
  Следующий ролик грузится заранее, лента бесконечная.
- Прокси: соединение с серверами видео по имени хоста, повтор при временном отказе и запасной путь по IPv4-адресу;
  число одновременных соединений ограничено (у прокси бывает лимит). «Проверить связь» теперь проверяет и видео:
  берёт настоящий поток и читает первые байты через прокси (в журнале — хост, код ответа, способ соединения).
- Вход в VK и Google: cookies читаются из хранилища WebView2 целиком (включая HttpOnly, все сайты VK и Google),
  в журнал идёт только количество cookies по доменам, без значений.
- Помощница сама выполняет поиск, «включить», открытие раздела и «ещё»; лайки, подписки, комментарии — только после
  подтверждения (Настройки → Голос и помощница).
- Голос: озвучка ответов (кнопка с динамиком в чате; у каждой помощницы свой тон) и микрофон в чате.
  Распознавание — через API активной конфигурации, если она умеет /audio/transcriptions, либо локальный whisper.cpp:
  Настройки → Голос → «Установить локальное распознавание» (~150 МБ, можно указать папку, например E:\AI\whisper).
  Для озвучки нужен русский голос Windows: Параметры → Время и язык → Речь.

Что было в 0.2.2
- Видео играет прямо в окне программы. «В отдельном окне (mpv)» — кнопкой под видео
  или в Настройки → Воспроизведение → «Где играть».
- Чат с помощницами: нажмите на героиню. Нужна активная конфигурация в Настройки → ИИ — API.
  Серверы в локальной сети (10.x, 192.168.x, 127.x) — напрямую, остальное — через прокси.
- Всё через прокси, включая обложки. «Проверить связь» показывает каждый шаг,
  «Журнал» — последние строки журнала без паролей и ключей.
- Вход в Google и VK: Настройки → Аккаунты → «Войти». Откроется окно Google/VK,
  войдите как обычно — окно закроется само. Если Google не пускает во встроенное окно,
  используйте «cookies.txt» (выгрузите из своего браузера, после импорта файл удалите).
  «Выйти» удаляет всё, что сохранено для входа.
- VK Видео: поиск сверху (вкладка VK). Ролики 18+ — только после входа в VK и по переключателю.

Также работает
- Поиск, Главная, Shorts, Подписки, «Обзор», каналы; История, «Смотреть позже», Избранное,
  плейлисты, загрузки — локально; импорт из Google Takeout; темы; SponsorBlock; прокси SOCKS5/HTTP.

Пароль прокси, API-ключи и cookies аккаунтов шифруются средствами Windows (DPAPI)
и не лежат в settings.json открытым текстом.

Файл не подписан, поэтому SmartScreen может показать «Windows защитила ваш компьютер» —
«Подробнее» → «Выполнить в любом случае».
